# The app icon

`icon.icns` is what ships. `icon.png` is the 1024×1024 master it was built
from. Both are generated by `../scripts/make-icon.py`; neither is hand-drawn,
so changing the brand means changing that script, not retouching a bitmap.

## What it is

A white "D" in Chillax at weight 500, on the brand teal, in the macOS squircle.

Every part of that comes from something already decided elsewhere:

| Element | Value | Where it comes from |
|---|---|---|
| Ground | `#00918A` | `oklch(0.575 0.135 190)`, the `--primary` token in `src/styles/globals.css`, converted to sRGB |
| Face | Chillax, `wght` 500 | `src/components/blocks/wordmark.tsx`, the one place a display face is allowed, and it pins 500 deliberately |
| Shape | superellipse, exponent 5, 824pt on a 1024pt canvas | macOS Big Sur geometry |

The teal is computed in the script rather than pasted as a hex literal, so the
provenance survives. If `--primary` ever moves, the conversion is one line to
re-run rather than a hex nobody can trace.

## The shape is measured, not guessed

A rounded rectangle is not the macOS shape, and the difference is visible when
the icon sits next to any other one in the Dock. The script draws a real
superellipse. MEASURED against `/System/Applications/Notes.app`, both rendered
at 1024:

| | full width | width at 12% height |
|---|---|---|
| Notes | 824 px | 628 px (76.2%) |
| this icon | 824 px | 622 px (75.5%) |

0.7% apart on the measure the corner radius actually controls. Do not "fix"
the corners by eye against that.

## Replacing the art

Edit `../scripts/make-icon.py` and re-run it, then rebuild the iconset:

```bash
python3 desktop/scripts/make-icon.py . desktop/build/icon.png
```

then regenerate `icon.icns` from that master (`sips` + `iconutil`, sizes 16
through 512 at 1× and 2×). Check the result at 16 px before accepting it: that
is the Finder sidebar, and it is where a display face usually falls apart. This
one stays legible there, which is why the "D" is set as large as it is.

The icon is baked in at package time, so it takes a full rebuild to see a
change in the app, it cannot be swapped into an existing `.app`.
